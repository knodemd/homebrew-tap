# Knode for Homebrew

```sh
brew install knodemd/tap/knode
```

Installs Knode for Mac, the `knode` command and the MCP server. Nothing to install yet: the first
release comes with [v0.1](https://github.com/knodemd/handbook/blob/main/06-roadmap.md).

| Path | What |
|---|---|
| `Casks/` | The Mac app |
| `Formula/` | The `knode` command line |
